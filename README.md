This project implements the K-Nearest Neighbors (KNN) classification algorithm using Python and Scikit-learn. It includes data preprocessing, feature scaling, train-test split, model training, prediction, and evaluation.
KNeighborsClassifier
Steps Followed
Imported libraries
Loaded dataset
Preprocessed data (handling missing values, encoding, scaling)
Split dataset into train and test sets
Trained KNN model
Evaluated performance
Tuned hyperparameters (K value, distance metric)
Tools Used
Python, Pandas, NumPy, Scikit-learn
Objective
To classify data using KNN and analyze model performance.
